// operating principles

How I Build Security

~/assume-breach

Assume breach

Design so a single compromise stays small — least blast radius, short-lived credentials, segmentation, and detection that assumes the attacker is already inside.

~/least-privilege

Least privilege, by default

Zero standing admin. Identity and access scoped to the minimum, computed from who you are — never from what the request claims.

~/shift-left

Shift left, prove right

Security lives in the SDLC, not after it. Threat-model before building; back every control with evidence an auditor — or an attacker — can't argue with.

~/paved-road

Make the secure path the easy path

Reusable middleware and paved-road defaults developers adopt instead of fight — so the right way is also the path of least resistance.

~/own-it-end-to-end

Own it end to end

From a line of code to the cloud control plane to the incident at 2 a.m. — I build, deploy, and operate the control, not just review someone else's.

~/automate-the-boring

Automate the boring, document the dangerous

Idempotent, reproducible infrastructure and evidence pipelines; plain-English writeups for the attack scenarios that actually matter.
